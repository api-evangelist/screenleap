# Screenleap

> Screenleap is a screen sharing and online meeting service with a REST-style developer API (api.screenleap.com/v2) for embedding live interaction — screen sharing, video/audio conferencing, chat and cloud recording — into your own website or online service. Authentication uses an account id and auth token passed as request headers over SSL.

## APIs
- [Screenleap API](https://www.screenleap.com/api): REST-style API to create, retrieve, list and stop screen share sessions.

## Operations
- createScreenShare — POST /screen-shares — create a session; returns viewerUrl + screenShareData
- listScreenShares — GET /screen-shares — list sessions (time/externalId filters, max 1000)
- getScreenShare — GET /screen-shares/{screenShareCode} — retrieve one session
- stopScreenShare — POST /screen-shares/{screenShareCode}/stop — stop an active session
- listRecentScreenShares — GET /recent-screen-shares — recent sessions
